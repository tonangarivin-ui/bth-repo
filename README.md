A self-contained make.fun referral page for developers who already build with AI coding agents. One promise: give your next agent session a shot at a cash bounty. The page explains public submissions, GitHub sign-in, prize uncertainty and USDC payouts. Every call to action uses https://make.fun/r/6sp8gq4y.

`index.html` contains all styles, uses system fonts and works without JavaScript. It makes no external requests on load. `ad.png` is its 1280×800 desktop screenshot at device scale 1 in light mode. No build step or dependencies.

## Run it

```sh
python3 -I -m http.server 18473 --bind 127.0.0.1
# Open http://127.0.0.1:18473 in your browser.
```
